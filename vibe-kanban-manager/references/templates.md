# 工作流模板

## 标准分析工作流

```
创建标准分析工作流：
- 名称: HCC 数据集分析
- 阶段: 环境准备 → 数据加载 → 模型运行 → 结果分析 → 报告生成
```

**生成的任务**:
1. `P0: 环境准备` (检查依赖、激活环境)
2. `P1: 数据加载` (加载 h5ad, 验证格式)
3. `T1: 模型运行` (执行 CartaPA)
4. `T2: 结果分析` (统计、可视化)
5. `P3: 报告生成` (汇总、导出)

## 并行实验工作流

```
创建参数扫描工作流：
- 基础任务: 模型训练
- 参数变体: lr=[0.001, 0.01, 0.1]
- 并行执行
```

**生成的任务**:
1. `EXP: 参数扫描主任务`
   - `EXP.1: lr=0.001` (并行)
   - `EXP.2: lr=0.01` (并行)
   - `EXP.3: lr=0.1` (并行)
2. `EXP_SUMMARY: 结果对比`

## 状态监控

### 任务状态流转

```
todo → inprogress → inreview → done
  ↑         │           │        ↑
  └─────────┘           │        │
        (失败重试)       └────────┘
                        (人工审核通过)
```

> **注意**: Agent 完成任务后设置为 `inreview`，`done` 仅由人工审核后设定。

### 批量状态查询

```python
list_tasks(project_id=PROJECT_ID, status="inprogress")
```
