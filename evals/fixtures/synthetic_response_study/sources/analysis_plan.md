# Synthetic response study analysis plan

本 evaluation fixture 以 sample 为分析单位，比较 `Control` 与 `Treatment` 的 `response_score` 描述性均值。固定输入为 24 个 synthetic samples，每组 12 个。

允许的结论上限为 association。报告必须清楚说明这是 synthetic evaluation，不得使用 causal wording，也不得作 clinical generalization。

Canonical report 使用中文 Markdown；Figure text、axis label、legend 和 filename 使用 English。
