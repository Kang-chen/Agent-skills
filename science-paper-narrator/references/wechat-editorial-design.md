# 科研公众号编辑与图版规范

## 先拆参考，不凭印象仿写

对参考 PDF 抽取以下可观察特征：

- 标题层级：总标题、概览、中文序号一级标题、蓝色编号小标题分别如何使用。
- 语言单位：随机抽取 10 个正文段落，判断每段通常包含几句、复杂句后是否有白话收束。
- 逻辑句式：记录对比句、设问句、转折句、限定句的功能，不复刻参考作者的固定措辞。
- 视觉节奏：统计每隔几个段落出现一张图，图片是整图还是 panel 裁切，是否保留原始英文图注。
- 强调方式：重点色只服务中心判断、关键数字和边界条件，避免整段变色。

## 默认文章版式

1. 标题采用“对象 + 核心变化 + 一个读者问题”，避免空泛的“重磅”“颠覆”。
2. “推文概览”用 4-7 个短段落完成熟悉参照、缺口、新能力、数据范围和中心判断。
3. 一级标题使用中文序号并居中；方法与结果的二级标题使用左对齐蓝色编号。
4. 正文以 1-3 句为一段。一个段落只承担一个动作：提出问题、解释设计、报告证据或划定边界。
5. 连续技术解释不超过 3 段；之后必须用“换句话说”式白话结论、图版或过渡句释放阅读压力。
6. 强判断与证据相邻；关键限制不要全部推迟到文末，可在对应结果后用一段短句及时校准。

## 蓝色阅读锚点合同

蓝色粗体要让读者在手机上扫读时看见全文推理骨架。先选意义，再检查密度；不得为了命中数字机械加粗。

- 语义组合：中心判断/过渡结论、关键证据与数字、方法设计或关键对象、限制/前提/验证边界四类都必须出现。尤其不能只有术语和数字。
- 目标节奏：正文每千中文字 6-9 处，蓝色字符约占 7%-10%，至少 80% 的实质内容小节有一处；5-10 处/千字、6%-11% 字符覆盖是可接受带。超出可接受带时必须返工或由独立审阅者给出逐处理由。
- 分布：概览通常 3-5 处，一般方法/结果小节 1-3 处，高潮与讨论各 2-4 处；任意连续两个实质小节不得都没有锚点。相邻锚点中位间距宜为 80-220 个中文字，超过约 450 字的空窗要复核。
- 形状：多数锚点是 8-35 个可见字符、脱离上下文仍成立的短语或分句。裸数字、五字以内名词和同一句拆成多个百分数只可作为少数例外；一个长段落不得大面积变蓝。
- 科学完整性：数字须连同比较对象或方向，限制须把否定词和验证边界一起纳入蓝色范围。结论框、小标题和相邻正文锚点不重复同一句。

机器校验只负责密度、覆盖、章节空窗、长度和碎片化警告。最终必须由未参与写作的审阅轮次逐项判断：蓝字是否命中最强证据而非装饰性主语；扫读能否复述问题、证据、高潮和边界；PDF 中是否每页有节奏而不出现蓝色成片。

## 中文母语化检查

- 优先使用直接、具体的动词，少用“旨在、得益于此、实现了、确立了、开辟了、得到升华”等公文化套语。
- 避免为显得正式而连续使用“该模型、该研究、其、并非、由此可见”；根据上下文改用省略主语、重复专名或更自然的“它、这一步”。
- 不把简单关系改写成抽象名词串。例如，将“受限于高昂的成本、通量规模及技术成熟度”改为“成本高、通量有限、技术尚未成熟”。
- 警惕营销式强化词，如“无缝支持、完美预测、核心突破、至关重要、指数级膨胀”；它们既损害中文自然度，也可能改变证据强度。
- 保留适量“先说判断、换句话说、这里需要说明”等口语路标，但同一表达不要反复出现。
- 完稿后朗读一遍：语序拗口、连续长句、主语重复或只能靠英文逻辑理解的句子必须重写。

使用外部模型润色时，锁定标题、段落顺序、图片、URL、数字和科学限定；将原稿与模型稿匿名化后交给独立审阅者盲测。模型改动幅度不是质量指标，保留原文也可以是更好的编辑判断。


## 图版台账

图版台账只是制作清单，不是图文本身。最终稿中每一行台账都必须落成真实图片资产、Markdown 图片引用和中文图注；不得用“配图建议”占位符代替执行。

每张候选图至少记录：

| 字段 | 要求 |
|---|---|
| 来源 | 原 PDF 页码 + Figure/panel |
| 叙事作用 | 该图回答的唯一问题 |
| 裁切范围 | 保留哪些 panel、图例、标尺和对照 |
| 必留边界 | 在源渲染页上标记所需内容的最外层 `required_bounds`；不能直接把计划裁框当成必留边界 |
| 放置位置 | 哪个段落之后 |
| 图后解释 | 看到了什么；不能说明什么 |

裁切规则：

- 删掉论文页眉、页码、周围正文和整段英文长图注。
- 不裁断 panel 字母、坐标轴、单位、图例、显著性符号、比例尺或关键对照。
- 如果全图缩到正文宽度后文字不可读，拆成 2-3 张局部图；不要单纯放大整页截图。
- 标题页截图只保留标题、作者、期刊或预印本状态；不把广告或网页导航混入正文。
- 图下中文说明优先写结论与证据边界，来源用小号灰字；不要逐句翻译原英文图注。
- 默认每 2-4 个短段落一个视觉节点。原论文图少时宁可降低密度，也不要重复同一图或引入无关装饰图。
- 用约 390 px 内容宽度模拟手机端预览；panel 字母、坐标、图例或样本量看不清时，必须拆图或缩小裁切范围。

### 裁图完整性验收

每张裁图经过两个独立关口：

1. **几何与来源校验**：crop manifest 记录 `source`、`crop`、`box`、`required_bounds`。运行 `scripts/validate_figure_crops.py`，确认裁框完整包住必留边界、尺寸正确且图片像素来自声明的源页区域。
2. **视觉语义校验**：检查生成的 review sheet。先看源页上的红色实际裁框与绿色必留边界，再看下方成品裁图；按上、下、左、右四条边逐一核对小标签和边框。主图看起来完整，但任何序列标签、轴标题、图例、显著性符号或关键对照被切掉，都判定失败。

`required_bounds` 必须从源页视觉检查得出，且应贴住最外层必留内容；它不能复制计划裁框坐标，否则无法发现同源的错误。实际裁框应在必留边界外保留安全余量。PDF 构建后还要再次检查缩放后的可读性和分页。

分页检查：

- 不让结论框孤悬页首，也不让标题与其首段分离。
- 避免只含来源列表的严重欠填充末页；可压缩来源区间距，或将来源并入最后一页的收束区域。
- 检查相邻两段是否出现相同起句、重复价值判断或图前图后的同义复述；保留更具体、更有证据的一处。
- 构建前运行 skill 自带的 `scripts/validate_article_assets.py`；公众号图文稿若没有图片、仍有配图占位符、图片文件不存在或缺少紧随图片的中文图注，必须判定失败。

## 六维盲测量表

使用未参与写作的 subagent 或独立审阅轮次，将成稿与参考材料逐项打 1-5 分：

1. 语言精炼：是否删除重复背景、无功能形容词和连续名词堆砌。
2. 描述句式：是否以对比、问题、证据、限定推进，而不是方法清单。
3. 行文段落：是否多数为 1-3 句，长技术段后有白话收束。
4. 标题层级：读者能否只看标题复述全文推理链。
5. Figure 排版与截取：手机端是否可读，裁切是否完整，图前图后是否解释其证据作用。
6. 科学谨慎：是否区分展示、内部一致性、回顾性验证、独立验证和实验因果证明。

另做一项“蓝色阅读锚点”专项判定，不并入六维平均分：量化合同通过，四类语义齐全，扫读能复述推理链，且没有碎片化、重复或科学限定丢失。专项不通过时继续修订。

任何一项低于 4/5，先修订对应位置再交付。参考文章本身若存在夸大、广告页或低信息密度图，不把这些缺陷复制进输出。
